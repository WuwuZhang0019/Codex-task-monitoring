## 身份、字段及关系契约

以下为逻辑字段，物理存储格式可在 M02 实施时选择；必需字段不能因格式选择而丢失。每个对象有稳定 `id`；引用必须指向同项目有效对象，删除或修订不得破坏历史引用。时间使用带时区的时间戳，记录来源与适用版本。

| 对象 | 必需字段与约束 |
|---|---|
| 项目 | id、名称、初始及当前方案版本引用、目标、项目验收条件、文件夹和任务引用、项目关闭记录 |
| 文件夹 | id、项目 id、外部标识或待绑定状态、名称；同名不能作为身份 |
| 任务线 | id、项目 id、唯一文件夹引用或待绑定、名称、目标、终点条件、站点及交接对象；绑定后只能有一个所属文件夹 |
| 聊天来源 | id、任务 id、文件夹 id、聊天外部标识或待绑定、仓库、工作树、分支、回执位置和时间；多个来源可指向同一任务 |
| 站点头 | 任务 id、稳定编号、名称、方案版本及章节、目标、范围、前置站点和验收项、合法后继；编号在任务内唯一 |
| 依赖边 | 前驱和后继的任务及站点身份、条件；跨线引用明确项目和任务，拒绝缺失、自环、重复及循环；合流逐边检查 |
| 方案版本 | id、项目 id、版本号、日期、原文、来源路径、章节、摘要、目标和验收条件、前版及变更影响；初版不可覆盖 |
| 回执 | id、项目/文件夹/任务/站点与方案版本、来源、时间、原文摘要或原文、交付、提交、各验收结果、未决事项、后继编号和范围；重复导入以来源身份及内容摘要识别并保持幂等 |
| 证据 | id、回执及验收项引用、位置、类型、适用交付版本、可用性与核验时间；引用存在不等于通过 |
| 核验 | id、规则版本、站点与回执、逐项结果和理由、证据引用及适用版本、交接结果、时间；追加记录 |
| 状态事件 | id、对象、事件类型、来源、时间、关联核验；开始、导入、核验、关闭、失效与修订均保留历史 |
| 关闭记录 | id、任务或项目、原目标、实际交付、验收、初始和当前方案符合性、偏差、交接对象、证据及时间；失效追加复核事件，不抹除关闭历史 |

方案初始版本以用户确认的原文及来源固定；后续修订新增版本并记录影响，不覆盖初始目标及旧核验。旧数据 source 可作为保留的来源文本，但缺来源和版本时不得虚构正式基线。核验只适用于记录的方案、交付与证据版本；影响发生变化须复核。

最小关系例：项目 P 含文件夹 F、任务 T，T 唯一归属 F；聊天 C1、C2 都记录 F/T，站点 S1 身份始终为 T/S1。其他文件夹 F2 同名回执不能自动归入 T。S3 可依赖 T/S2 和另一任务 U/S1，只有两边有效通过且交接条件满足才可开始。

## 状态与判定

报告状态是来源自述；验收状态为通过、未通过、待核验；交接状态为匹配、不匹配、待核验并单独检查全部前置。待开始且前置、交接通过显示暗色可开始；仅有实际开始事件才显示绿色。有效验收通过显示红色；阻塞、等待和证据失效均有文字或图标。旧 done 只保留为已记录完成，验收待核验。

判断顺序：核对身份和适用版本、逐项验收与证据、阻塞、合法后继范围及全部依赖；模糊语义待核验。A 为本站未完成；B 为必要证据不足；C 为本站完成但后继依赖未满足；D 为本站完成且交接和前置通过；E 为任务线结束并交接；F 为项目条件也全部通过；G 为范围冲突或须改变方案。A/B/D 提供相应指令；C/E/F/G 不生成虚假下一步。关闭要求全部必要站点及终点通过、证据有效、无交付阻塞且对象范围明确；项目另行检查项目级条件。

推演：缺证据→B、不红、不关闭；编号相同但范围不符→交接不匹配、不推进；两前置仅一项通过→等待另一对象；交接通过无开始事件→暗色可开始；四线关闭但集成未完成→项目保持开放；已关闭证据失效→追加待复核事件并停止作为有效依赖，保留原关闭历史。这些是契约审查，不是产品运行验证。

## 旧数据迁移边界

只读检查 `app/data/projects.json`：数据库 version 1，两个项目，一个三站 NV21 样本及一个空项目；样本站点为两个 done、一个 active。未读取或复制实际业务文本到本文件。旧 schema 将 source、goal、步骤和自由文本直接嵌入项目，严格字段校验会拒绝新字段。

迁移时保留原始 source、goal、项目 ID、站点 ID、依赖、原状态、总结、下一步、阻塞、证据、revision 和时间；保留旧原始快照及映射来源。创建独立的待绑定任务及文件夹占位，不依据名称猜测身份；未知聊天和基线来源保持未知。不得生成历史验收通过、回执、关闭或开始事件。旧状态作为历史报告展示，验收待核验。空项目不得伪造站点。

迁移前停止写入并备份整个数据目录及校验摘要；在隔离副本上验证新 schema、记录数、字段、依赖及重开结果，再原子切换。保存迁移版本和来源摘要，重复执行识别已迁移数据，不重复生成实体；失败保留原文件及备份并明确报错，从备份恢复后再重试。具体迁移与恢复测试属于 M02，本次未修改数据。
