# 面板 UI 与桌面交互细化方案

日期：2026-11-10

状态：新路线模块细化方案，待实施

本文按已确认需求拆分模块职责、接口和验收要求。02_需求与视觉基线中的原指导方案及 UI 设计作为需求来源，本文与其他六份细化方案共同组织后续开发。

## 目标与输入输出

输入为路线模块生成的项目、方案、步骤、依赖、状态和关联快照，输出为面板展示、选中项和用户操作请求。沿用原 UI 设计的黑色底、圆角、细边框和横向站点风格。

## 开发内容

1. 核对 `prototypes/top-panel/src/main.ts`、`styles.css`、`drawer.ts` 与实际桌面入口，确定组件复用范围。
2. 实现顶部紧凑条和下方展开区。紧凑条以 600×38 DIP 为设计基线，展开区建议宽 960 DIP、高度上限 640 DIP，实际尺寸受工作区约束。
3. 按业务项目纵向分区，项目内按方案分组，每条工作树路线横向排列。规范化后的工具步骤编号用于站点，原编号在详情中追溯，会话编号用于关联入口。
4. 区分步骤顺序、跨路线依赖和补充事项来源。汇合处表达全部前置完成条件，未知规划用虚线开放端。
5. 展示待执行、执行中、已阻塞、已完成、已取消及最后更新时间。延续原型红色完成、绿色执行中的语义，同时配文字与图标。
6. 实现项目折叠、分支折叠、深层聚焦、已结束分支入口和当前站定位。首次最多展示三条直接分支，剩余分支提供数量及异常统计。
7. 主体单一纵向滚动，项目内路线共享横向滚动，固定路线标签。刷新保持阅读位置与选中项。
8. 详情展示原文内容、验收要求、进展、证据、会话与工作树关联。实现键盘焦点、Esc 分层退出、明确收起按钮及空态。
9. 对接桌面置顶、显示区域、展开收起和完成事件提示，验证显示缩放、小屏及焦点行为。

## 接口与依赖

依赖路线与状态管理提供只读快照，依赖会话关联模块提供跳转结果。数据存储模块保存用户折叠与定位偏好。UI 的操作请求经业务校验后更新，业务状态以保存回执后的快照为准。

## 验收

覆盖三个项目、六条工作树路线、三十站长路线、八条分支和深层补充事项。检查长标题、连线避让、异常计数、断线提示、失败跳转和阅读期间收到更新。真实桌面记录尺寸、缩放、焦点和展开收起效果。

## 交付

面板组件、桌面适配、样例数据入口及截图和原生操作记录。完整视觉细节继续引用原 UI 设计文档。
