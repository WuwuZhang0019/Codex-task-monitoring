# 测试方案 02：第二步展开三个子步骤

日期：2026-11-13

状态：方案已编写，待执行

## 测试约定

- 各步骤执行内容为空，以预设返回值代替实际任务执行。
- 返回值仅允许“成功”和“失败”两个值；本方案全部预设为“成功”，无等待时间。
- 共三个主步骤 A、B、C；B 向外展开三个子步骤 B-01、B-02、B-03。
- 执行顺序为 A → B-01 → B-02 → B-03 → B 判定成功 → C。
- B 开始后保持执行中，只有 B-03 返回“成功”，才能判定 B 返回“成功”。B-01 或 B-02 成功时不能提前完成 B。
- 子步骤按顺序执行，前一个步骤成功后才能开始后一个步骤；C 必须等待 B 成功。
- 表中为预设结果，实际返回值在执行后记录。

## 三个主步骤

| 步骤 | 编号 | 前置步骤 | 执行内容 | 预设返回值 | 成功判定条件 |
|---|---|---|---|---|---|
| 第一步 | A | 无 | | 成功 | 直接返回成功 |
| 第二步 | B | A | | 成功 | 展开下表三个子步骤，B-03 成功后返回成功 |
| 第三步 | C | B | | 成功 | 直接返回成功 |

## 第二步展开的三个子步骤

| 子步骤 | 编号 | 前置条件 | 执行内容 | 预设返回值 |
|---|---|---|---|---|
| 1 | B-01 | B 已开始 | | 成功 |
| 2 | B-02 | B-01 成功 | | 成功 |
| 3 | B-03 | B-02 成功 | | 成功 |

## 验收要求

- 主步骤恰好三个，第二步包含三个子步骤，执行内容全部为空。
- A、B-01、B-02、B-03、C 均返回“成功”。
- B-03 成功前，B 保持执行中，C 保持待执行。
- B-03 成功后判定 B 成功，再执行 C。
- 三个主步骤均成功时，方案测试通过。
