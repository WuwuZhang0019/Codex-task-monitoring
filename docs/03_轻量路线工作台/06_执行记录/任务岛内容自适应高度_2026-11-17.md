# 任务岛内容自适应高度

日期：2026-11-17
状态：已实现、已验证并更新本机运行版

任务岛现在根据当前显示任务的自然内容高度调整下边界，顶部位置保持稳定。完整卡片、紧凑列表和不同任务之间切换时会平滑伸缩；超过屏幕可用高度后，仍使用原有侧边滚轮上下浏览，路线区域继续支持横向滚动。

原问题有两层限制：前端展开高度固定在约 480 px，原生透明窗口又固定为 640 逻辑像素。只放开前端高度，仍可能被原生窗口裁剪。本次同时取消这两处固定高度，以显示器工作区为上限，并为阴影保留空间。测量使用内容自身尺寸，避免外框动画反复影响测量而产生抖动。侧边滚动切换当前任务时保留阅读位置；屏幕可用高度变化时立即限制实际边界。
