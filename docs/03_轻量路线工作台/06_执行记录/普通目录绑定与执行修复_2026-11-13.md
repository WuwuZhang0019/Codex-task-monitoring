# 普通目录绑定与执行修复

日期：2026-11-13

状态：源码修复、回归、本机安装更新及运行服务工具发现通过；新会话实际方案测试待用户执行

## 问题与修复

普通文件夹中的返回值测试在执行前被 Git 核验拦截。服务自动绑定及执行期上下文检查原先强制要求 Git 工作树根目录、分支和 HEAD，导致用户无法在自己的非 Git 项目中使用工作台。

服务现在核验实际项目目录，非 Git 上下文使用 `branch: null`、`head: null`；不初始化仓库，不依赖本插件开发路径。MCP 契约和工具说明同步开放此表示，插件版本提升为 0.1.13，Skill 入口和执行、关联参考文件写明普通目录使用方式。固定会话映射允许没有分支，Git 分支和多工作树协调仍使用严格的 `inspectWorktree`。

目录必须存在且为目录，普通目录使用规范化真实路径。已有 Git 元数据、Git 根目录不符、分支错误或 Git 检查异常不能降级为普通目录。没有安装 Git 时，普通目录仍可使用，但祖先中有 Git 元数据的目录必须先恢复 Git 检查能力。非 Git 目录转为 Git 后，旧绑定失效，须重新绑定。
