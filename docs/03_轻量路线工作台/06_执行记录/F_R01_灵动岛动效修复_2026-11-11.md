## 四项原因与修复

| 用户原问题 | 已验证原因 | 本轮处理及验收 |
|---|---|---|
| 没有连续展开、收起动效 | 条和面板直接挂载/卸载，原生每次直接切换窗口尺寸 | 固定宿主不移动；同一进度驱动 CSS 轮廓与 Win32 SetWindowRgn，展开 280ms、收起 240ms，内容分层入退场，保留双向中间帧 |
| 收起后与屏幕上沿有间距 | 原宿主位置主动增加 8 DIP | 去掉偏移，主体与原生窗口 top 均贴工作区 top；现场 top=0 |
| 展开后不自动收起 | 默认 pinned=true，且固定展开与系统置顶混用 | 默认悬停 180ms 预览、移出 350ms 收起；点击才固定展开，再点解除；详情阅读保持，关闭详情后恢复原悬停/固定规则；浮窗始终原生置顶 |
| 与原灵动岛不融合 | 条与展开区各自有背景、边框、圆角，外侧又是独立黑色画布 | 单一透明宿主、单一黑色轮廓及一圈边界；顶部摘要独立固定在原 600×38 锚点，下面内容属于同一主体，无独立条底圆角或双边框 |

## 实现与来源

复用本仓库原型的悬停/固定语义，并参考本仓库归档的“灵动岛式连续展开与收起动画独立实现方案”第 4/5 节和自有 U01 原生 probe。只复用自有样例，没有引入新的动效库、第三方源码或新插件。

- `app/src/useIslandMotion.ts`：配置与帧共用单一串行驱动，从当前已确认进度反向；动画中的 resize 不丢弃，先重算环境再续接；IPC 失败最多自动恢复一次，持续失败停止并可显式点击重试；减少动态效果使用缩短过渡。
- `app/src/LightPanel.tsx`、`light-panel.css`：统一轮廓、固定摘要、非固定默认值、统一悬停延迟和详情保持，收起显式解除固定。非浮窗模拟入口保持原布局。
- `app/src-tauri/src/panel_shape.rs`、`lib.rs`：960×678 DIP 固定宿主，包含 600×38 紧凑区与 960×640 内容；按工作区/DPI 上限裁定。透明、无阴影、不可原生拖动缩放，首次显示前先裁为紧凑区；串行窗口线程应用顶部直角/底部圆角区域，旧帧拒绝，初始化以外不按开合改变窗口矩形。显示面板使用非激活方式，不在悬停路径 set_focus。
- `app/tests/island-motion.mjs`、`island-ipc.mjs`：正常交互与受控 IPC 异常的分环境证据。`light-ui.mjs` 支持独立证据目录，后继回归不覆盖 C 历史目录。

原生区域成功时 HRGN 交系统管理，失败释放，额外保护像素不超过 1 物理像素。面板只读/偏好 IPC 边界保留，新增帧/固定命令只允许 panel 窗口调用，不向浮窗开放授权和业务写入口。
