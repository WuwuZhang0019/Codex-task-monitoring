`/api/light-mcp` 提供九工具发现与调用，由插件令牌逐次认证。`/api/light-access/grants`、`revoke`、`confirm-publication`、`confirm-binding` 需要现有私有 UI 认证，Rust 主窗口白名单仅开放这四项确认操作。普通插件凭据访问确认入口实测 403。

授权回调取得 input、binding 和 step 详情。跨主体绑定冒用、仅有提议权限时撤销责任绑定，以及跨项目、方案或主体使用预留执行 ID 均受到拒绝。旧字符串执行预留只保留历史，已有执行及原请求仍可读取回放。

MCP 协议包装在领域事务外执行，业务失败按事务回滚。网络掉响应及可能已经提交的内部错误返回 unknown，原键查询支持外层发布完整语义并兼容旧领域记录。新建请求前先核对旧结果。
