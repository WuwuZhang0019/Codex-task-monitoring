日期：2026-11-12

## 用户要求与实现

用户要求自动绑定、隐藏会话 ID 和目录等技术字段，使用简短说明与按钮，并显示是否真正连接 Codex。

任务岛 MCP 页改为连接状态、一句话说明和一个按钮。点击“连接 Codex”一次开启本机自动关联模式，允许本机 Codex 同步工作台项目；后续普通绑定在服务端核验实际 Git 根目录、分支及起始 HEAD 后直接确认。跨会话接手沿用原有完整范围、旧绑定版本和未结束执行核验，不放宽项目验收和方案发布条件。旧版限范围授权仍按原规则处理。

状态来自已初始化 MCP 客户端提供的名称及会话标识，每 10 秒更新心跳，35 秒过期；设置页约每 3 秒刷新。区分未开启、等待 Codex 接入、已连接、连接中断、旧版连接和服务不可用。其他 MCP 客户端不被显示为 Codex。多聊天各自续期，断开一条不影响另一条。关闭连接撤销对应插件授权；打开设置仅查询状态，不创建授权。心跳只查询工具，不重试业务写入。

首次安装允许 MCP 在没有连接配置时等待，页面保存配置后同一进程按需读取并接入。连接凭据仅在本机受保护目录保存，界面不显示令牌。提交结果不明时阻止重复点击。新版外部插件为 0.1.7，身份和工具数量保持不变。
