# 通用接入入口与动态应用列表

日期：2026-11-12

状态：实现并验证，安装记录待补记

## 行为

MCP 页仅保留一个“复制接入指令”入口，可重复点击接入不同应用。目标 Agent 识别实际应用名称，通过 --app 提供给助手；不再预置四张应用卡片。复制请求不预绑定产品，首次完成后锁定到所选应用，不能用同一请求再接另一个应用；再次点击取得新请求。

应用显示名由目标 Agent 登记，身份按规范化名称生成稳定安全 ID，兼容旧 Codex/Claude Code/dsh/WorkBuddy 标识。目录仍按安全 ID 隔离；服务拒绝路径注入与保留标识。连接列表及面板按钮依据已登记连接动态生成，不将未接入产品预先显示为连接对象。历史绑定、旧连接和独立断开保留。注册的名称不代表对产品品牌的独立认证，状态依据 MCP 实际通信。
