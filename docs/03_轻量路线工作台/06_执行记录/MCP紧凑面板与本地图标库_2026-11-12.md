# MCP 紧凑面板与本地图标库

日期：2026-11-12

状态：实现、回归与运行版交付完成

## 改动

- 移除展开面板顶部“全部”和“未分配”两个按钮。默认仍展示所有任务；再次点击当前应用按钮取消筛选，因此历史无归属任务仍可访问。
- MCP 连接项改为一行：图标、应用名、状态按钮，移除重复说明和独立状态圆点。绿色“已连接”可断开；灰色“连接”可连接；红色“连接失败”可重试；黄色“连接中”显示沿按钮边缘流动的光效，可取消连接。
- 服务读取失败将已有连接项标红，恢复后以服务最新状态为准。已启用配置不等同于实际连接成功，绿色仍以 MCP 有效通信状态为依据。
- 保留一个通用复制接入指令入口。实际接入应用动态显示，图标库不创建虚假连接；未知应用使用通用图标。
- 设置页增加默认折叠的备用图标库，支持中文别名和英文名称搜索。下载 93 个品牌及应用、161 个 SVG，约 326 KiB，运行时全部从本地读取。顶部应用按钮复用同一批图标。

## 来源与复现

图标来源：[LobeHub Icons](https://lobehub.com/zh/icons)，实际资源取自其[官方仓库](https://github.com/lobehub/lobe-icons/tree/a177c1e817204f8ddc0c8993610ca674fc6d9767)，固定版本 `a177c1e817204f8ddc0c8993610ca674fc6d9767`。原始 SVG 未修改；MIT 许可、版权归属和各文件 SHA-256 位于外壳 `public/ai-icons/` 下的 LICENSE、NOTICE.md 和 manifest.json。

下载脚本：`app/scripts/fetch-island-ai-icons.py`。运行 `python app/scripts/fetch-island-ai-icons.py --shell-root G:/rust/windows-dynamic-island` 可重新取得固定版本的资源和目录；`--tree` 可指定已缓存的 GitHub 目录树。

流光参考 [Magic UI Shimmer Button](https://magicui.design/docs/components/shimmer-button) 的沿边缘发光效果，采用本项目 CSS 实现，没有复制其组件或添加依赖。系统开启减少动态效果时停用流光动画，保留黄色状态及文字。
