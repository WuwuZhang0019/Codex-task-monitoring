# D 独立服务与新壳连接说明

日期：2026-11-12

状态：D实施记录；正式闭环验收结果以阶段回执为准

## 启动与停止

业务服务独立于新旧桌面窗口运行。MCP与新壳只发现已有服务，不会自动启动第二个写入者。用户已删除的旧工作台不再作为连接和确认入口前置。

在业务仓库app目录执行下列命令。data-dir必须为既有业务数据目录的绝对路径，不复制或另建一份正式数据库：

```powershell
node desktop/service.mjs start --data-dir C:/Users/Zyf/AppData/Local/com.codextaskmonitor.workbench/data
node desktop/service.mjs status --data-dir C:/Users/Zyf/AppData/Local/com.codextaskmonitor.workbench/data
node desktop/service.mjs stop --data-dir C:/Users/Zyf/AppData/Local/com.codextaskmonitor.workbench/data
```

start遇到既有独立所有者时附着同一实例；遇到由旧桌面进程拥有的服务时明确拒绝DESKTOP_OWNER_ACTIVE，避免误认为旧UI退出后仍能保持。停止等待已接受请求排空及生命周期清理后返回；停止后须显式start恢复。相同数据目录仍由OS租约保护，第二写入者不能取得所有权。

## 新壳连接与权限

新壳默认真实服务模式，原生层从LOCALAPPDATA/com.codextaskmonitor.workbench/data发现所有者。ISLAND_WORKBENCH_DATA_DIR仅作为原生启动环境中的绝对数据根覆盖项，测试用独立目录；前端不能提交数据目录、服务地址或令牌。浏览器显式?workbench=simulation用于隔离演示，连接失败不会自动切模拟数据。

普通浮窗只使用runtime-private/panel-session.json内的最小凭据，限GET /api/light-panel和PUT /api/light-panel/preferences。管理会话与面板会话分别签发并绑定ownerGeneration。发现记录不含令牌；凭据文件由当前用户/SYSTEM私有ACL保护。原生请求限定loopback、固定路径，禁代理和重定向，5秒超时、8MiB响应上限，并在响应后复查所有者代际。

新壳常规设置内提供连接授权和绑定确认。用户本人核对项目、聊天、宿主和工作树后签发，连接令牌由原生层写入受保护的Codex桥配置，不复制到前端、URL或日志。新壳不提供任意业务API代理，点击阶段仍只选中查看。宿主不支持聊天或工作树跳转时使用复制标识/路径。

## 阅读与未知结果

快照保持既有固定ID、五状态、依赖、绑定和服务revision。失败显示离线、未授权或不兼容并保留最后有效快照；旧revision不能覆盖新状态。健康连接与最后成功同步分别记录。首次读取失败仍有可见错误，卸载后慢轮询不再安排新定时器。

阅读偏好首次成功回读后才允许保存；新壳滚动项使用island/*命名空间，保留其他偏好字段。保存串行化，失败不冒称已持久化；业务revision不因阅读改变。新连接离线后恢复时，先提交保存的选中阶段，再恢复其详情滚动位置。

未知业务结果仍须由原MCP主体携带原项目、操作类型与eventId查询；新壳仅有eventId时保持unknown，不能扫描显示快照冒称正式查询，也不创建替代事件。正式业务上报继续使用既有绑定、版本、授权及幂等门禁。

## 验收边界

隔离STDIO/HTTP、浏览器测试桥、原生Rust HTTP测试和正式项目结果分别留证。浏览器与构建通过不等于原生UI或正式写入验收。完整DPI/多屏/安装恢复和用户观感属于E；许可与发布属于F。旧UI回退入口已不可用的事实交E核对，本阶段不恢复旧安装。
