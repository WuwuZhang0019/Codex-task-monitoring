先按锁定 Fork 的 bun.lock 安装依赖并运行开发入口。以下命令在 G:\rust\Codex-task-monitoring\app 执行：

~~~powershell
$env:PLAYWRIGHT_BROWSERS_PATH='G:\rust\Codex-task-monitoring\app\test-results\island-A\pw-browsers'
npx playwright install ffmpeg
node tests/island-a-browser-baseline.mjs
~~~

录制脚本：G:\rust\Codex-task-monitoring\app\tests\island-a-browser-baseline.mjs。可用 ISLAND_A_BASE_URL、ISLAND_A_BROWSER_EXE、ISLAND_A_BROWSER_OUTPUT 显式覆盖运行地址、浏览器和结果目录。脚本不改 Fork，不写真实服务，不依赖用户浏览器会话。
