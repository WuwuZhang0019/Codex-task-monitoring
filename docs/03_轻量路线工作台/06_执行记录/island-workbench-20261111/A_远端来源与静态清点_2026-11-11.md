## 模块、插件、快捷键与后台入口

[src/modules/index.ts](https://github.com/WuwuZhang0019/windows-dynamic-island/blob/e286d9045746837bf1960e0d13b7ed572b8d9e50/src/modules/index.ts) 注册以下 12 个产品模块。按用户范围均为模块入口移除候选；实现分别从 src/modules/<id>/ 继续追踪。尚未逐个穷举内部采集/监听，不把此注册表当作完整后台矩阵。

| 模块 key | 候选范围与待核对入口 |
|---|---|
| music | 音乐 UI 与媒体采集 |
| ai-agents | Agent UI 及 claude/codex/antigravity 采集；凭据/Hook 不擅自删除 |
| ask | Ask UI、命令与快捷键 |
| find | 屏幕查找 UI、识别及快捷键 |
| notifications | 通知模块 UI 及监听 |
| activities | 实时活动 UI；与外壳提示/本地 API 的依赖须继续核对 |
| shelf | 暂存架 UI 与文件/拖放入口 |
| clipboard | 剪贴板 UI 与监听 |
| github | GitHub UI、请求与凭据读取 |
| hydration | 提醒 UI、前端计时器待深入 |
| monitor | 系统监控采集；须与显示器/多屏外壳逻辑区分 |
| clock | 时钟模块入口；不能据此删除独立 appearance.idleClock 偏好 |

[src-tauri/src/providers/mod.rs](https://github.com/WuwuZhang0019/windows-dynamic-island/blob/e286d9045746837bf1960e0d13b7ed572b8d9e50/src-tauri/src/providers/mod.rs) 注册 14 个 Provider：activities、music、notifications、ask、find、shelf、clipboard、claude、codex、antigravity、github、monitor、calendar、shortcuts。[lib.rs](https://github.com/WuwuZhang0019/windows-dynamic-island/blob/e286d9045746837bf1960e0d13b7ed572b8d9e50/src-tauri/src/lib.rs) 的 setup 无条件遍历 .start()，因此仅删除页面入口不能证明后台停止。

这 14 项都是依赖核对候选，当前没有证据支持直接删除整文件。activities 的提示/本地 API、monitor 与 display/多屏壳层尤其需要区分。每个 Provider 的线程、订阅、凭据读取、停止及资源释放仍待逐项追踪。
