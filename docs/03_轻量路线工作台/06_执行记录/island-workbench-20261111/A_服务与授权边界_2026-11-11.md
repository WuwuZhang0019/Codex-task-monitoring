## D 接线差距与承接

| 差距 | D 必须提供的行为与验收 |
|---|---|
| 服务依赖旧桌面进程 | 提供受控独立启动、停止、恢复及发现机制；明确旧 UI 隐藏、旧 UI 退出与服务生命周期关系。服务独立化前保留旧宿主作为回退 |
| 新旧 UI 与 MCP 共享实例 | 全部按同一数据根及 owner generation 发现既有实例；同项目回读同一 revision，避免新外壳启动第二写入者 |
| Fork 无现有私有会话 Runtime | 设计受控原生 WorkbenchClient 适配；不把旧私有令牌复制进前端配置、日志或 URL，不允许任意 Origin/CORS |
| 面板令牌与 MCP 令牌用途不同 | 读取/阅读偏好与业务事件操作分别按真实能力开放；保留最小路径和方法白名单，不以本机端口代替授权 |
| 确认流程与身份 | 正式登记、发布、绑定及开始仍用真实确认入口；复用既有身份和原事件，完成后回读并单独记录 synced |
| 连接状态与恢复 | 区分所有者停止、端口/generation 变化、授权撤销、超时、旧版本、未知结果；不自动切换模拟数据或覆盖新 revision |
