# 任务岛侧边滚轮平滑切换

日期：2026-11-17
状态：已完成实现、浏览器验证及本机更新

展开完整卡片时，在任务列表右侧空白处每拨动一格滚轮，按方向切换一个任务。滚动使用约 380 毫秒的缓出过渡，窗口高度同步变化；连续或反向拨动从当前位置接续，首尾不越界。动画期间锁定目标任务，避免动态高度逻辑重新判断可见项后直接跳转。图内滚轮保留横向滚动；紧凑列表和单个超高任务保留原有滚动。

实际外壳源码位于 `G:/rust/windows-dynamic-island/src/components/island/useContentHeight.ts`。本仓库扩展 `app/tests/island-adaptive-height.mjs`，以只读项目副本和内存中的多任务夹具进行隔离验证。

两种外观共 24 项浏览器检查通过，涵盖一格一项、三任务连续切换、逐帧中间位置、快速反向、首尾边界、减少动画模式、高矮任务高度变化、图内横向滚轮、屏幕高度上限及稳定性。前端 lint、构建、108 项前端测试、Clippy 和 41 项 Rust 库测试通过。

证据见 [browser-report.json](assets/smooth-wheel-20261117/browser-report.json)。旧 `island-route-selection.mjs` 在展开前因模拟数据的缩略节点数已从 3 变为 4 而停止，未作为本次验收；本次用当前只读项目补验图内横向滚轮。Bun 前端测试使用 `bun test ./src` 限定目录，避免 `bun test src` 将 `src-tauri/target` 内的打包后端测试也匹配进去。

浏览器结果不等同于原生桌面滚轮交互验收。
