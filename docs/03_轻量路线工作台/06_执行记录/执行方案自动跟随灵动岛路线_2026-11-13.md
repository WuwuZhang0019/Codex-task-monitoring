# 执行方案自动跟随灵动岛路线

日期：2026-11-13

状态：修复及浏览器回归通过，运行版更新中

## 问题与修复

原自动切换只覆盖新登记方案，没有覆盖已在列表中的方案开始执行。因此用户按单个文档继续执行后，列表有路线但缩略岛仍显示旧阅读目标。

业务服务在步骤实际进入 running 时更新默认阅读目标，包含从阻塞恢复；普通 running 进度及原事件重放不重置用户之后手动选择。子步骤通过父阶段定位所属路线，持久阅读偏好与执行状态独立保存。

外壳读取新增的 running 事件及步骤状态变化来切换方案、路线和展开/收起共用阅读记忆，清除隐藏目标的旧应用筛选。即使步骤在两次轮询间开始并完成，也能通过新开始事件切到该路线。没有新开始事件时不抢回手动选择，冷启动沿用服务保存的默认阅读目标。
