# 接入指令与安装后自动连接

日期：2026-11-12

状态：实现与本地验证完成；部署记录见下方

## 用户要求与实际行为

将“复制连接配置”改成自然语言“复制接入指令”。四个应用（包括 Codex）都提供该按钮。用户将指令发送到对应 Agent 应用的对话窗口，Agent 检查实际版本、安装或合并本应用 MCP 配置及配套执行说明，校验后运行本机助手 --complete，自动完成原“连接”操作，无须用户回任务岛点击。已开启的应用仍可独立断开。

指令携带 --describe、--complete 和本机请求文件路径，不含接入票据、连接令牌或管理令牌。--describe 返回无令牌配置与配套 Skill 路径；配置格式由目标 Agent 根据真实应用支持选择，dsh 明确核对 profile/patch，不盲目写通用 JSON。--complete 通过受限接入请求自动开启所选应用，不能管理其他应用或项目。

复制时仅创建 30 分钟有效、固定应用的请求，票据保存在受保护的本机目录。受控管理入口签发请求，公共本机端点只接受票据兑换；拒绝 Origin、非法应用、失效票据和范围变化。相同请求重试返回同一连接；已有自动连接复用原主体和令牌，保护正在执行的绑定。断开会同时撤销该应用先前复制的请求，不能通过重放自动重新开启。

助手不读取 owner-session 管理凭据，使用不走环境代理、不跟随重定向的本机 HTTP 通道。原配置备份后原子保存，保存失败保留恢复/原请求重试语义。仅开启授权不等于已连接：助手不发冒充宿主的心跳，只有对应应用真实加载 MCP 后界面才显示已连接。宿主必须新会话或审批时，指令要求准确报告等待条件。
