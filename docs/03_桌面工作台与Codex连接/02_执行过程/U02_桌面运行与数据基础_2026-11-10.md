## 4. 本轮修正及适用范围

Windows 扩展路径传入 Node 后出现 lstat G: 错误，宿主改用规范化资源路径。原权限保护递归作用于应用根目录，影响 WebView2，并在对子文件去除继承后造成重开失败，现已收窄为业务 data 目录并保留子文件正常继承，最终原生重开及 ACL 记录通过。受影响目录均为本任务新建的应用/烟测目录，已恢复其适用权限。

原生退出时 Rust Child::wait 关闭 stdin，停止命令与 EOF 可能先后触发两次停止调用。已改为共用同一停止 Promise，并增加命令和 EOF 同时到达的回归，最终原生退出产生完整标记并清理发现文件。

本次使用隔离数据副本与独立安装目录验证。用户实际旧 app/data 尚待用户在首次初始化界面选择迁移来源。当前安装为 0.2.0 调试烟测包，正式发行矩阵归 U07。现有 React 业务界面及 AI 区域沿用历史页面，桌面 API 白名单覆盖本阶段管理路径，完整 Codex 草稿、九工具、授权和候选核验归 U03—U05。浮窗当前为宿主壳，原始“任务航线”样式复用、连续动效和组合状态接线归 U06。
