# 顶部路线面板演示

日期：2026-11-09

状态：独立模拟原型

由 create-tauri-app 4.7.5 的 vanilla-ts 模板生成，使用 Tauri 2 与 TypeScript。此处只演示面板外观与交互，全部路线与事件为固定模拟数据。

## 使用

双击本目录的 `启动演示.cmd`，已构建程序直接启动，首次需先安装依赖并构建。

```powershell
npm ci
npm run tauri build -- --debug --no-bundle
```

开发预览使用 `npm run tauri dev`。网页预览使用 `npm run dev`，网页仅供界面检查。

- 启动显示顶部居中的黑色紧凑条，悬停 180ms 展开，移出 350ms 收起。
- 点击紧凑条或固定按钮，保持展开。点击右上角向上箭头收起，× 退出。
- 模拟按钮延迟 3 秒触发，便于移出鼠标或切换到其他软件输入。事件自动展开，8 秒后收起，悬停和固定时保持展开。
- 执行结束进入待核验。模拟验收通过只改变 D06，D07 仍等待 D05。
- 关闭提醒只清除未读计数，重置恢复全部样例。

原型窗口使用非焦点模式，按实际可见尺寸调整，顶部锚定主显示器工作区。屏幕组合、DPI、原生焦点及动画效果需要现场体验。非焦点模式下可用按钮收起，Esc 仅适用于网页预览获得焦点的情况。

## 范围

本原型独立于现有工作台。路线、提醒和未读状态仅保存在当前进程内。完整桌面工作台、真实 Codex 连接、持久化及安装交付仍按原方案另行实施。
